# JavaScript Learning Journey

A daily log of my JavaScript learning.

## Daily routine

Two independent parts each day:

1. **Read** about one JS topic and write my notes in `notes/`.
2. **Solve** one JavaScript problem in `solutions/` — any topic, unrelated to the notes.

## Structure

```
notes/       one markdown file per day  (YYYY-MM-DD.md)
solutions/   one .js file per day       (YYYY-MM-DD.js)
```
